# 🐾 Pet Shop Billing System

## 📌 Project Overview
Akshaya Pet Shop Billing System is a simple Python-based console application designed to manage pet purchases and calculate bills automatically. Customers can select pets from different categories, choose breeds, enter quantities, and generate the final bill.

## ✨ Features
- Multiple pet categories.
- Different breeds with individual prices.
- Automatic price calculation.
- Quantity-based billing.
- Purchase multiple pets in one transaction.
- Running total calculation.
- Final bill generation.

## 🐶 Pet Categories
- Dogs
- Birds
- Aquarium Fish
- Small Pets

## 🛠️ Technologies Used
- Python
- Input and Output Operations
- Conditional Statements (if-elif-else)
- While Loop
- Arithmetic Operations
- Variables

## ⚙️ How to Run
1. Clone this repository.
2. Open the project in VS Code or any Python IDE.
3. Run the Python file.
4. Select a pet category.
5. Choose the breed and enter the quantity.
6. Continue shopping or finish the purchase.
7. View the final bill.
